# 🚀 Masar 3.0 - نظام إدارة التدريب المتكامل

## ✨ التحديثات الجديدة (الدفعة الأخيرة)

### 📚 شاشة تفاصيل الكورس المحسّنة
- عرض كامل لمعلومات الكورس (المدرب، الفرع، التقييمات)
- نظام تقييمات بالنجوم مع التعليقات
- عرض المحاور والجدول الزمني
- إحصائيات التسجيل (عدد الطلاب / السعة)
- زر التسجيل المباشر للمجموعات المتاحة
- تصميم Apple Liquid Glass أنيق

### 👨‍🏫 لوحة المتطوع المتكاملة
#### Tab 1: إدارة الجلسات
- بدء جلسات جديدة بكبسة زر
- QR Code حقيقي للتسجيل (يتضمن: ID الجلسة، الوقت، المدرب)
- عرض الطلاب المسجلين مع إمكانية التسجيل اليدوي
- تسجيل الحضور (حاضر / متأخر / غائب) بشكل فوري
- إحصائيات مباشرة (عدد الحاضرين، المتأخرين، الغائبين)

#### Tab 2: إنشاء كورس جديد
- نموذج كامل لإنشاء كورس (عنوان، تخصص، وصف، عدد المحاضرات)
- اختيار الفرع من القائمة
- تحديد السعة والقاعة وتاريخ البدء
- إنشاء مجموعة (batch) تلقائياً مع الكورس

#### Tab 3: سجل الحضور
- عرض تاريخ الجلسات السابقة
- تفاصيل الحضور لكل جلسة

### 👨‍💼 لوحة الأدمن الشاملة
#### Tab 1: نظرة عامة
- إحصائيات شاملة (المستخدمين، الطلاب، المتطوعين، الفروع)
- آخر التقييمات من المستخدمين
- بطاقات إحصائية بتدرجات لونية

#### Tab 2: إدارة المستخدمين
- عرض كل المستخدمين مع البحث
- معلومات كاملة (الاسم، الإيميل، الهاتف، الدور)
- فلترة حسب الدور (طالب، متطوع، مشرف، أدمن)

#### Tab 3: الفيدباك
- تقييمات الكورسات مع التفاصيل
- تقييمات المدربين
- تقييمات الفروع
- عرض التعليقات والأسماء (للأدمن فقط)

#### Tab 4: الفروع
- عرض كل الفروع مع التقييمات
- معلومات التواصل (الهاتف، العنوان)
- متوسط التقييم لكل فرع

### 🗄️ طبقة البيانات (Supabase Layer)
- `src/data/queries.ts` - كل الـ queries لقاعدة البيانات
- جلب الكورسات مع التقييمات والإحصائيات
- جلب الفروع مع التقييمات
- إدارة الحضور (إضافة / تحديث)
- إنشاء الكورسات والمجموعات
- نظام التقييمات الثلاثي

### 🎯 نظام التقييمات الثلاثي
1. **تقييم الكورسات** - الطلاب يقيّمون الكورس
2. **تقييم المدربين** - الطلاب يقيّمون المدرب
3. **تقييم الفروع** - الطلاب يقيّمون الفرع

الأدمن يرى كل التفاصيل (من قال ماذا)، والمتطوع يرى الإحصائيات فقط.

## 📊 قاعدة البيانات

### الجداول الرئيسية (25+ جدول)
- `profiles` - المستخدمين
- `branches` - الفروع (8 فروع RTC حقيقية)
- `courses` - الكورسات (6 كورسات جاهزة)
- `batches` - المجموعات
- `sessions` - الجلسات
- `attendance` - الحضور
- `point_events` - دفتر النقاط
- `streak_weeks` - الاستريك
- `gamification` - الجيميفيكيشن
- `course_ratings` - تقييمات الكورسات
- `instructor_ratings` - تقييمات المدربين
- `organization_ratings` - تقييمات الفروع
- `certificates` - الشهادات
- `excuses` - الأعذار
- `badges` - الشارات (12 شارة)

### Row Level Security (RLS)
كل جدول محمي بسياسات RLS:
- الطالب يرى بياناته فقط
- المدرب يرى مجموعاته فقط
- الأدمن يرى كل شيء

## 🚀 التشغيل

### 1. إعداد Supabase
```bash
# افتح Supabase SQL Editor
# انسخ محتوى: supabase/001_complete_schema.sql
# شغّل الـ SQL
```

### 2. تفعيل Google OAuth
1. Supabase Dashboard → Authentication → Providers
2. فعّل Google
3. أضف Client ID و Client Secret
4. Redirect URL: `https://YOUR_PROJECT.supabase.co/auth/v1/callback`

### 3. تشغيل التطبيق
```bash
npm install
npm run web
```

### 4. تسجيل الدخول كأدمن
- سجّل دخول بـ: `shakerabdallah66@gmail.com`
- ستحصل على صلاحيات أدمن تلقائياً
