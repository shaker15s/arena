# 05 — نظام التصميم والموشن (Design & Motion System)

> **الهدف:** هوية بصرية «جبارة» لكن *منضبطة* — كل بكسل من توكن، وكل حركة من كتالوج موثق. لا قرارات عشوائية أثناء البرمجة.

---

## 1. روح التصميم (Design DNA) — 4 صفات

1. **«زجاجي دافئ» (Warm Glass):** طبقات زجاجية فاتحة الظلال — فخامة Apple بدون برود.
2. **عربي أصيل أولًا:** الخط، الإيقاع، اتجاه القراءة — التطبيق يُولد عربيًا ثم يترجم، لا العكس.
3. **بيانات كلعبة:** أرقام ضخمة، حلقات تقدم، دروع ولهيب — الإحساس باللعبة في كل مكان.
4. **الحركة = معنى:** لا حركة للزينة. كل أنيميشن إما يؤكد فعلًا (نجاح/خطأ) أو يوجّه العين، وله نسخة «حركة مخفضة».

## 4. الشبكة والأشكال (Layout & Shape)
- **Spacing:** شبكة 4pt صارمة: `4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`.
- **Radii:** شاشات وحوارات 28 · بطاقات 20 · بطاقات صغيرة 16 · أزرار 14 · Chips/حبوب pill.
- **لمس:** حد أدنى 48×48 لكل عنصر تفاعلي (أعلى من معيار 44 — راحة إبهام).
- **Bento Grid:** شاشات «اليوم» والداشبورد تُبنى بشبكة 2 عمود (موبايل) / 4 (تابلت) ببطاقات بأوزان بصرية متفاوتة.
- **Glassmorphism المحدود:** فقط للطبقات العائمة (التاب بار، الهيدر المصغر، المودالز): خلفية `surface.glass` + blur + border خفيف — **ممنوع النص فوق glass بدون خلفية مبهمة كافية (قاعدة تباين)**.
- Safe-area محترمة دائمًا؛ المحتوى الرئيسي في المنتصف العلوي لقابلية الوصول بيد واحدة.

## 5. نظام الموشن (Motion Design System) ✨

### 5.1 الستاك الحركي
| الطبقة | الأداة | لماذا |
|---|---|---|
| حركات UI الأساسية والانتقالات | **Reanimated 4** (Worklets على UI thread) | 60/120fps حقيقي بدون JS bridge |
| الرسوم المخصصة (لهيب، حلقات، كونفيتي، جسيمات) | **React Native Skia** | GPU-canvas |
| أنيميشن الجاهزة (Lottie) | **Skottie (Skia-based)** | +63% معدل فريمات على الأجهزة الضعيفة، ملفات ≤ 1MB قاعدة صارمة |
| الإيماءات | Gesture Handler | سحب طبيعي فيزيائيًا |
| اللمسيات | expo-haptics | مصفوفة موحدة §5.5 |

### 5.2 اللغة الحركية الموحدة (Motion Tokens)
```ts
duration = { micro: 140, fast: 220, standard: 300, emphatic: 480, celebration: 700 }
easing   = { standard: cubic(0.2, 0.8, 0.2, 1) /* Apple-out */,
             exit: cubic(0.4, 0, 1, 1) }
spring   = { gentle:  { damping: 18, stiffness: 150 },   // بطاقات
             snappy:  { damping: 22, stiffness: 260 },   // أزرار/تاب
             playful: { damping: 9,  stiffness: 180 } }  // شارات/احتفال (bounce)
scalePress = 0.96 // كل زر عند الضغط + هابتك light
```
**قواعد:** المدة ≤ المبلغ المكتوب أعلاه · لا حركتين ثقيلتين متزامنتين على نفس الشاشة · أي حركة > 300ms لها هدف سردي مبرر.

### 5.3 كتالوج الحركات لكل شاشة (Motion Catalog)
| الشاشة/اللحظة | الحركة | الأداة | المدة |
|---|---|---|---|
| Splash | تجمّع جزيئات اللوجو → توهج | Skia | 1200ms |
| Onboarding | Parallax + نصوص staggered 80ms | Reanimated | — |
| التنقل بين الشاشات | iOS: slide · Android: shared-axis fade-scale · Reduced: fade نقي | Nav+Reanimated | 300ms |
| كتالوج → تفاصيل كورس | **Shared Element** (الصورة تكبر = Hero) | Reanimated | 300ms |
| الهيدر | Collapsing + تحوّل glass عند السكرول | Reanimated | — |

| العدادات الرقمية | **Odometer roll** بالأرقام العربية Tabular | Skia text | 500ms |
| حلقات التقدم | تمتلئ بـ spring + توهج عند الإكمال | Skia | 600ms |
| **لحظة الحضور الناجح** | ✓ يرسم stroke → كونفيتي 80 جسيم → «+10» تطير للرصيد → لهيب يلتهم | Skia جسيمات | 700ms تاج |

### 5.4 الحركة المخفضة (Reduced Motion) — إجباري لا اختياري
عند تفعيل المستخدم إعداد النظام: كل الحركات أعلاه تتحول لـ **crossfade 200ms** بدون حركة مكانية، والكونفيتي لومضة خفيفة. يُفحص في QA لكل شاشة احتفالية.

### 5.5 مصفوفة اللمسيات (Haptics)
| الحدث | النمط |
|---|---|
| ضغط زر عادي | `impactLight` |
| تأكيد/اختيار | `impactMedium` |
| نجاح (حضور/إصدار) | `notificationSuccess` |
| تحذير (كود منتهٍ) | `notificationWarning` |
| خطأ | `notificationError` |
| سحب/تمرير قوائم حساسة | `selection` |

### 5.6 ميزانية الأداء الحركي (محسومة)
- 60fps أرضي و120fps حيث الشاشة تدعم · Frametime ≤ 16ms لكل الأنيميشنات على جهاز متوسط.
- Lottie JSON ≤ 1MB وهاتف ضعيف ضمن مصفوفة الاختبار.
- لا أنيميشن على JS thread أبدًا — كل شيء Worklet/Skia.
- الصور: أحجام مضغوطة WebP + كاش قرصي · قوائم طويلة عبر FlashList.

## 6. الأصوات (Sound — اختياري V1.5)
نغمات خفيفة قصيرة (نجاح/نقطة/شارة) ≤ 0.5s، افتراضيًا **مغلقة** وتُفعل من الإعدادات — احترامًا لبيئة القاعات.

## 7. معايير الوصول (Accessibility)
- أحجام خط ديناميكية (Dynamic Type) حتى 130% بدون كسر التخطيط.
- VoiceOver/TalkBack labels عربية لكل عنصر تفاعلي.
- التباين AA مفروض آليًا · لا نقل معلومة باللون وحده (أيقونة + نص دائمًا).
- RTL: مرآة كاملة للتخطيط والأيقونات الاتجاهية — يُفحص آليًا في CI.
