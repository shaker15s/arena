# 02 — الشخصيات (Personas) والفلوهات الكاملة

> **الهدف:** كل مستخدم يعرف طريقه من أول ثانية، وكل فلو موثّق بدقة تكفي أن لا يسأل مبرمج ولا مصمم «وبعدين؟» أبدًا.

---

## الجزء الأول: الشخصيات

### 🎓 أ. الطالب — «عمر»
- **من هو؟** طالب جامعة أو حديث تخرج (16–35)، بياخد كورس مهاري (جرافيك، برمجة، لغات) في فرع رسالة القريب منه.
- **بيفتح التطبيق ليه؟** يسأل: *محاضرتي الجاية امتى وفين؟ حضوري كام؟ نقاطي والستريك بتاعي؟ شهادتي هستحقها امتى؟*
- **ألم يحلّه:** نسيان المواعيد، عدم معرفة نسبة حضوره، إحساس أن مجهوده لا يُرى.
- **POV نجاحه:** يفتح التطبيق فيقول «عارف كل حاجة في 5 ثواني».

### 👨‍🏫 ب. المتطوع/المدرب — «أ.سارة»
- **من هي؟** متطوعة بتدرّس كورس في مجموعة (Batch)، وقتها محدود وتكره الأعمال الورقية.
- **بتفتح التطبيق ليه؟** تفتح الجلسة، تشوف مين حضر، تقفل، تكتب تقرير سريع، تراجع أعذار.
- **ألم يحلّه:** كشوف الحضور الورقية، عدّ الغياب يدويًا، متابعة الأعذار على واتساب.
- **POV نجاحها:** «الجلسة اتنظمت من غير ما أحسب حاجة بإيدي».

### 🛠️ ج. المشرف — «الأستاذ محمود»
- **من هو؟** مسؤول فرع/لجنة التدريب، ينظم الكورسات والمدربين ويصدر الشهادات ويحاسب على الجودة.
- **بيفتح التطبيق ليه؟** ينشئ كورس وباتش، يعيّن مدرب، يتابع نسب الحضور، يصدر شهادات، يعدّل قواعد اللعبة.
- **ألم يحلّه:** إكسيل متناثر، شهادات بتتحرر يدويًا، مفيش رؤية على مستوى الفروع.
- **POV نجاحه:** «الفرع كله قدامي في داشبورد واحدة، وأول كورس اتعمل في 10 دقايق».

### 🦸 د. الأدمن العام (Super Admin)
- يملك المنصة كلها: الفروع، تعيين المشرفين، السياسات العامة، قواعد اللعبة الافتراضية.

## الجزء الثاني: فلوهات الدخول والانطلاق

### F1 — أول تشغيل + المصادقة (Passwordless OTP)
```
Splash (حركة لوجو 1.2s)
   │
   ▼
Onboarding (3 سلايدز Lottie — هل التطبيق مفهوم في 30 ثانية؟)
   │
   ▼
شاشة الترحيب: [ابدأ الآن] / [عندي حساب]
   │
   ▼
إدخال رقم الهاتف (تحقق صيغة مصرية فوري + خيار البريد الإلكتروني)
   │
   ▼
OTP 6 أرقام (تلصق تلقائي SMS autofill / بصمة بعد أول نجاح)
   │
   ├──► حساب قديم؟ ──► تحميل الملف ──► شاشة اليوم
   │
   └──► حساب جديد ──► إكمال الملف (الاسم / الفرع الأقرب / صورة اختيارية)
                              │
                              ▼
                     رسالة ترحيب + شارة «البداية الصح» محجوزة
                              │
                              ▼
                       شاشة اليوم (فارغة بإرشاد ذكي)
```
**قواعد محسومة:**
- الجلسة محفوظة مشفرة (SecureStore) — لا إعادة دخول كل مرة.
- بصمة/وجه لفتح سريع اختيارية من الإعدادات.
- لو الدور «متطوع/مشرف» يتحدد من الأدمن العام — الطالب الجديد دايمًا يبدأ طالبًا.

### F2 — الطالب ينضم لأول كورس (الفلو الذهبي للطالب)
```
شاشة اليوم فارغة ─► CTA «استكشف الكورسات»
   │
   ▼
استكشف: كتالوج بكروت Bento + بحث فوري + فلاتر (الفرع / المجال / مستوى)
   │
   ▼
تفاصيل الكورس: نبذة + مخرجات + جدول المجموعات + المقاعد المتاحة + المدرب
   │
   ▼
اختيار المجموعة ─► تأكيد الانضمام (Bottom Sheet بالتفاصيل)
   │
   ├──► مقاعد متاحة ─► انضمام فوري + ترحيب متحرك + تذكير تلقائي قبل أول محاضرة
   │
   └──► مكتملة ─► «انضم لقائمة الانتظار» ─► إشعار فور توفر مقعد
   │
   ▼
خريطة الرحلة تظهر في «رحلتي»: مسار عمودي بـ N عقدة = N محاضرة
```
### F3 — الحضور اليومي (قلب التطبيق النابض)
```
إشعار تذكير قبل المحاضرة بـ 60 دقيقة
   │
   ▼
شاشة اليوم: كارت «محاضرتك بدأت — سجّل حضورك» (يظهر فقط أثناء الجلسة النشطة)
   │
   ▼
فتح الماسح (كاميرا + إطار متحرك + هابتك خفيف)
   │
   ▼
مسح QR الدوّار على شاشة المدرب
   │
   ▼
تحقق سيرفر: التوكن صالح؟ داخل النافذة؟ لم يسجل قبلًا؟   (RPC واحدة Idempotent)
   │
   ├──► نعم ─► شاشة نجاح: كونفيتي + هابتك نجاح + «+10 نقاط» + لهيب الستريك يطير
   │
   └──► لا ─► بطاقة هادئة: سبب واضح (انتهى الوقت / مسجّل مسبقًا / كود قديم)
                  + زر «كود الـ 6 أرقام» كاحتياطي
```
**قواعد محسومة:**
- حاضر في أول 15 دقيقة = `present` (+10). من 15–30 = `late` (+7). بعدها الحضور مقفول (يحتاج عذر).
- التسجيل يتعمل مرة واحدة فقط (Idempotency — ضغطتين متتاليتين = نتيجة واحدة).

### F4 — المدرب يدير محاضرة
```
شاشة اليوم (مدرب): كارت «محاضرة النهاردة 6:00م — محاسبة متقدمة»
   │
   ▼
[ابدأ الجلسة] ─► شاشة الجلسة الحية (Live Session)
   │
   ├── QR دوّار عملاق (يتجدد كل 25 ثانية + عداد دائري)
   ├── عداد حضور لايف يطلع مع كل مسح (Real-time)
   ├── شريط الزمن: متبقي X دقيقة لغلق الحضور
   ├── [رصد يدوي] لطالب جهازه تعطل (بحث بالاسم + سبب إلزامي)
   │
   ▼
[أنهِ الجلسة] ─► تأكيد ─► السيرفر يغلق التسجيل ويحاسب الغائبين تلقائيًا
   │
   ▼
تقرير الجلسة (نموذج من 3 حقول فقط: إنجزنا / مقدر / تحديات) ─► [إرسال]
   │
   ▼
ملخص فوري: حضروا X من Y — نسبة الدفعة — زر «تصدير الكشف PDF»
```

### F5 — الأعذار (العدل قبل العقاب)
```
غاب الطالب؟ ─► يفتح أعذاري ─► [عذر جديد] ─► اختيار الجلسة + سبب + مرفق صورة اختياري
   │
   ▼
يصل إشعار للمدرب ─► شاشة الأعذار الواردة ─► [قبول] / [رفض مع ملاحظة]
   │
   ├──► قبول ─► الحالة تتحول «معذور» + الستريك يتجمّد تلقائيًا (لا يُكسر) + نقاط جزئية؟ لا: 0 نقاط لكن الستريك محفوظ
   └──► رفض ─► يبقى غياب + إشعار للطالب بالسبب
```
**قاعدة محسومة:** المعذور لا يكسب نقاط حضور، لكن لا يخسر الستريك — العذر المقبول = Streak Freeze مجاني.

### F6 — إصدار الشهادات (ختام الكورس)
```
المدرب/المشرف يقفل الباتش ─► السيرفر يحسب الأهلية: حضور ≥ 75% (قابلة للظبط من القواعد)
   │
   ▼
شاشة «إصدار الشهادات»: قائمة المستحقين ✓ / غير المستحقين ✗ (مع سبب لكل واحد)
   │
   ▼
[إصدار الكل] ─► توليد شهادات بسيريال فريد + QR تحقق ─► إشعارات فورية
   │
   ▼
الطالب يستلم: إشعار + الشهادة في محفظته + كونفيتي إنجاز + +100 نقطة + شارة «صائد الشهادات»
   │
   ▼
مشاركة كصورة PNG فخمة أو PDF — ورابط تحقق عام لأي جهة توظيف
```

### F7 — المشرف ينشئ أول كورس (معالج البداية)
```
لوحة المشرف فارغة ─► معالج «ابدأ مركزك» 6 خطوات بشريط تقدم:
   1. الفرع (الاسم، المحافظة، العنوان، صورة)
   2. اللجان (تدريب / تنظيم / متابعة)
   3. أول كورس في الكتالوج (الاسم، المجال، الوصف، عدد المحاضرات القياسي)
   4. أول مجموعة (المدرب، السعة، الجدول الأسبوعي، تاريخ البدء، القاعة)
   5. ضبط قواعد اللعبة (نقاط الحضور، نافذة التأخير، نسبة الأهلية) — بقيم افتراضية ذكية مقترحة
   6. النشر + مشاركة رابط/QR الانضمام للطلاب
   │
   ▼
تهنئة متحركة «مركزك على الهواء 🎉» ─► لوحة التحكم الحية
```
> التفصيل الكامل لليوم الأول الحقيقي في [وثيقة السيناريو الذهبي](07-first-course-golden-path.md).

### F8 — فلوهات التعافي (Recovery — اللي بيفرّق المحترف عن الهاوي)
| الحالة | السلوك المحسوم |
|---|---|
| انقطع النت أثناء المسح | الماسح يعلمك بهدوء «لا يوجد اتصال» + زر إعادة — لا كراش ولا توست مخيف |
| رجع الطالب بعد انقطاع طويل | شاشة «أهلًا بعودتك» تلخص ما فاته + الستريك يظهر بحالة صادقة غير عقابية |
| حذف الأدمن كورسًا فيه خطة؟ | ممنوع حذف باتش نشط — أرشفة فقط مع تحذير واضح (بيانات الحضور مقدسة) |
| ضغط «تسجيل حضور» مرتين بسرعة | Idempotency: نفس النتيجة، لا نقاط مكررة أبدًا |
| فشل RPC | رسالة عربية ودودة من خريطة أخطاء موحدة + زر «حاول مجددًا»، لا أكواد خام |

## الجزء الثالث: مصفوفة «من يرى ماذا»

| القدرة | الطالب | المدرب | المشرف | الأدمن العام |
|---|---|---|---|---|
| الاستكشاف والانضمام | ✅ | ✅ | ✅ | ✅ |
| المسح للحضور | ✅ | — | — | — |
| بدء/قفل الجلسة + QR دوّار | — | ✅ (مجموعاته) | ✅ (فرعه) | ✅ |
| رصد يدوي للحضور | — | ✅ بمجموعاته | ✅ | ✅ |
| مراجعة الأعذار | يرى أعذاره | ✅ يقبل/يرفض | ✅ | ✅ |
| إنشاء/تعديل الكورسات والباتشات | — | — | ✅ لفرعه | ✅ للكل |
| منح نقاط يدوية | — | ✅ بحد أقصى شهري (قاعدة سيرفر) | ✅ بحد أعلى | ✅ بلا حد مع سبب |
| قواعد اللعبة (نقاط/نسب/نوافذ) | قراءة فقط | قراءة فقط | ✅ لفرعه (ضمن حدود عامة) | ✅ افتراضيات عامة |
| إصدار الشهادات | — | ✅ لباتشه | ✅ | ✅ |
| إدارة الأدوار | — | — | ✅ طالب↔متطوع | ✅ مشرف↔أدمن عام |

**كل صف أعلاه يترجم لـ Route Guard + فحص صلاحية داخل RPC نفسها (دفاع مزدوج).**
