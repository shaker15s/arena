# 03 — خريطة الشاشات الكاملة (Screen Atlas)

> **الهدف:** توصيف كل شاشة في مسار 3.0 قبل كتابة سطر واحد: الغرض، المكونات، البيانات، حالات الواجهة، والأنيميشن المخصص.
>
> **اتفاق التوثيق:** كل شاشة لها: الهدف 🎯 · المكونات 🧩 · البيانات 🗄️ · الحالات ⚙️ (Loading/Empty/Error/Offline) · الحركة ✨

---

## شجرة التنقل العامة

```
Root Stack
├── (public)  Splash → Onboarding → Auth(OTP) → CompleteProfile → VerifyCertificate (deep link)

│    ├── ⌾ [زر المسح المركزي FAB]

├── (volunteer) Tabs

│    + LiveSession, SessionHistory, StudentRecord, ManualMark, Analytics
└── (admin) Tabs
     ├── لوحة التحكم  ├── التنظيم (Org)  ├── المستخدمون  ├── المركز (Hub)  └── الإعدادات
     + OrgWizard, BranchEditor, CommitteeManager, CourseCRUD, BatchCRUD,
       IssueCertificates, BroadcastComposer, PointsRules, BadgeStudio, UserDetail, AuditLog
```

## 1. الشاشات العامة (Public)

### S01 — Splash 🌅
- 🎯 إقلاع أنيق يخفي التحميل، يقرأ الجلسة ويوجه فورًا.
- 🧩 Logo مرسوم يتجمّع من جزيئات (Skia Particles) → توهج → انتقال.
- ⚙️ لو أول مرة → Onboarding · لو مسجل → دوره يحدد التاب.
- ✨ Lottie خفيف ≤ 1MB، زمن ثابت 1.2s ثم fade.

### S02 — Onboarding (3 سلايدز)
- 🎯 إقناع في 30 ثانية: «نظّم كورسك / احضر بمسحة / اجمع نقاطك وشهادتك».
- 🧩 Lottie لكل سلايد + تكرار Parallax + مؤشر نقاط متحول + زر «تخطي».
- ✨ دخول متدرج للنصوص (stagger 80ms)، سلايد أفقي بسلاسة spring.

### S03 — Auth (OTP)
- 🎯 دخول بدون كلمة مرور.
- 🧩 حقل هاتف بعلم مصر + تحقق فوري · 6 مربعات OTP بلصق تلقائي · عداد إعادة إرسال · خطأ يهز الحقل (shake) لا يرعب.
- ⚙️ خطأ شبكة / كود منتهي / محاولات كثيرة → رسائل عربية هادئة.
- ✨ انتقال هاتف→OTP بحركة بطاقة تنزلق؛ نجاح OTP = tick متحرك ثم push للرئيسية.

### S04 — Complete Profile
- 🧩 الاسم الثنائي، اختيار الفرع (قائمة مدن→فروع)، صورة أفاتار اختيارية بنسبة قص 1:1.
- ✨ Progress 3 خطوات علوي؛ حفظ = confetti صغير.

### S05 — Verify Certificate (عام — Deep Link)
- 🎯 أي جهة توظيف تتحقق من الشهادة بدون تسجيل دخول.
- 🧩 إدخال سيريال أو مسح QR → بطاقة نتيجة: اسم حاملها، الكورس، الفرع، تاريخ الإصدار، ختم «موثّقة ✅».
- ⚙️ سيريال غير موجود → بطاقة حمراء هادئة «غير موثّقة — تأكد من الرقم».

## 2. شاشات الطالب (Student)

### S10 — اليوم (Today) — *الشاشة الأم*
- 🎯 مركز القيادة: إجابة «إيه اللي عليّ دلوقتي؟» في 5 ثواني.
- 🧩 **Bento Grid:**
  - بطاقة الجلسة الحالية (لو في جلسة نشطة الآن): [سجّل حضورك] زر زجاجي ضخم.
  - بطاقة «محاضرتك الجاية»: العنوان، اليوم، الوقت، القاعة + زر تذكير.
  - شريط علوي: 🔥 عداد الستريك الأسبوعي · ⭐ رصيد النقاط · 🏅 ترتيب الدوري — كلها تفتح تفاصيلها.
  - بطاقة أقرب شارة قابلة للكسب بشريط تقدم.
- 🗄️ `get_my_next_session` + `get_my_gamification` + الجلسة النشطة Real-time.
- ⚙️ فارغ (لا كورسات) → Empty State بـ Lottie + CTA استكشف · أوفلاين → بانر + آخر كاش.
- ✨ دخول البطاقات متسلسل من الأسفل · عدادات الأرقام Odometer · لهيب الستريك حالته (هادئ/متوتر كل خميس مساءً).

### S11 — استكشف (Explore / Course Catalog)
- 🧩 بحث فوري (debounced) + Chips (المجال/الفرع/المستوى) + بطاقات كورس: صورة، عنوان، شارة مجال ملونة، عدد محاضرات، مقاعد متبقية، تقييم النجوم.
- 🗄️ كتالوج منشور فقط + مقاعد `batch_seat_counts` لايف.
- ⚙️ لا نتائج → إيموجي + اقتراحات · أوفلاين → الكاش مع وسام «نسخة محفوظة».
- ✨ **Shared Element Transition:** صورة بطاقة الكورس تكبر وتصبح غلاف شاشة التفاصيل (Hero).

### S12 — تفاصيل الكورس
- 🧩 غلاف متدرج + Tabs: «عن الكورس» (محاور — نصوص تنظيمية فقط **بدون فيديو**) / «المجموعات» (المدرب، الجدول، القاعة، مقياس المقاعد)/ «التقييمات» (نجوم + تعليقات).
- ⚙️ باتش مكتمل → زر «قائمة انتظار» · انضممت بالفعل → «اذهب للرحلة».
- ✨ Header ينكمش مع السكرول (Collapsing) + ستيكي CTA سفلي.

### S13 — الانضمام (Bottom Sheet)
- 🧩 تلخيص الاختيار + موعد أول محاضرة + [تأكيد الانضمام].
- ✨ نجاح: أنيميشن «مقعد محجوز» + هابتك نجاح + بطاقة تهنئة تطير لمكانها في رحلتي.

### S14 — رحلتي (Journey) — قائمة الكورسات
- 🧩 بطاقة لكل كورس منضم: Progress Ring بنسبة الحضور + «محاضرة 3 من 8» + حالة الأهلية للشهادة (✓ مؤهل / تحتاج N).
- ✨ الحلقات تمتلئ بنابض عند الفتح.

### S15 — خريطة الرحلة (Course Journey Map) — *التوقيع البصري*
- 🎯 تحويل كشف الحضور لمسار لعبة متعة بصرية (إلهام Duolingo Path) — **للحضور فقط، لا محتوى**.
- 🧩 مسار عمودي متعرج بعُقد = محاضرات: مكتمل ✅ (أخضر) · الحالية 🔵 (نابضة) · مقفلة 🔒 (رمادية) · فائتة معذورة 🛡️ / غياب ✕ · عقدة نهائية = شهادة 🏆.
- 🧩 بين العقد: شارة مكتسبة هنا! نقاط مكتسبة تطفو.
- ✨ سكرول سلس · نبض العقدة الحالية · عند إكمال عقدة: تتلوّن وتطلق شرارة.

### S16 — سجل الحضور (Attendance History)
- 🧩 بطاقة لكل محاضرة: الكورس، العنوان، اليوم/التاريخ/الوقت، الحالة الملونة (حاضر✓/متأخر⏰/غائب✕/معذور🛡️)، نقاطها. فلاتر Chips + ملخص: الالتزام% وعدّاد الأهلية 75%.
- ⚙️ فلتر بلا نتائج → حالة فارغة رقيقة.

### S17 — ماسح الحضور (Check-in Scanner)
- 🎯 تسجيل في أقل من 3 ثواني.
- 🧩 كاميرا بإطار زجاجي متحرك + فلاش + [إدخال الكود اليدوي 6 أرقام] احتياطي.
- ⚙️ إذن كاميرا مرفوض → شرح + زر إعدادات · QR قديم/منتهي → «اطلب من المدرب الكود الجديد».
- ✨ خط ليزر يمسح داخل الإطار · عند النجاح: تكبير خفيف ثم شاشة نجاح.

### S18 — نجاح الحضور (Success Moment) — *أهم لحظة احتفال*
- 🧩 ✓ ضخم يرسم نفسه (stroke animation) + «+10 نقاط» تطير للرصيد + لهيب الستريك يلتهم قلبًا صغيرًا + زر «متابعة».
- ✨ **Confetti Skia + هابتك نجاح + صوت اختياري خفيف** — هذه اللحظة مدروسة نفسيًا (متعة فورية = تثبيت العادة).

### S19 — محفظة النقاط (Points Wallet)
- 🧩 الرصيد الكلي بخط Display + Level Badge + تقدم للمستوى التالي + دفتر الحركات (Ledger): «حضور محاسبة +10 · 22 أغسطس».
- 🗄️ `point_events` — مصدر الحقيقة، لا رصيد مخزن يتعارض.

### S20 — الدوري الأسبوعي (League)
- 🎯 منافسة أسبوعية عادلة بتصفير (درس ClassDojo/BuddyBoss).
- 🧩 اسم الدوري الحالي (برونزي→ماستر) بأيقونة درع + جدول الترتيب (أنت مميز بإطار متوهج) + **منطقة صعود خضراء ومنطقة هبوط رمادية** + عداد «ينتهي خلال 2 يوم: 5 س» + تبويب «نجوم صاعدة» للجدد.
- ⚙️ أول أسبوع → «دوريك الأول يبدأ الاثنين».

### S21 — الإنجازات (Achievements Hall)
- 🧩 شبكة شارات: مكتسبة (ملونة متوهجة) / مقفلة (رمادية + قفل + «المتبقي: 2 حضور متوالٍ»). الندرة بإطار ملوّن: عادي/نادر/ملحمي/أسطوري.
- ✨ ضغط شارة مكتسبة → تنبثق بـ spring لعوب + تدوير 3D خفيف.

### S22 — شهاداتي (Certificate Wallet)
- 🧩 بطاقات الشهادات المصدرة (تصميم رسمي فخم) → S23 العارض.
- ⚙️ فارغ → «أول شهادة تستنى التزامك 💪».

### S23 — عارض الشهادة
- 🧩 الشهادة كاملة + السيريال + QR التحقق + أزرار: مشاركة كصورة PNG / تحميل PDF / نسخ رابط التحقق.
- ✨ دخول الشهادة بحركة «ختم» ينطبع.

### S24 — أعذاري (Excuses)
- 🧩 قائمة أعذاري (قيد المراجعة/مقبول/مرفض) + [عذر جديد]: اختيار الجلسة، سبب، صورة مرفق.
- ⚙️ رفض → عرض ملاحظة المدرب بوضوح.

### S25 — الإشعارات
- 🧩 مجمعة باليوم: جلسات، نتائج أعذار، شارات، شهادات، بثّ من المركز. شارة عداد على التاب.

### S26 — تقييم الكورس (بعد آخر محاضرة — Sheet)
- 🧩 5 نجوم + تعليق اختياري → +5 نقاط عند الإرسال.

### S27 — حسابي / الإعدادات
- 🧩 الأفاتار، الاسم، المستوى، الستريك الطويل، تعديل الملف، اللغة (عربي/English فوري)، الثيم (فاتح/داكن/النظام + وضع OLED)، الإشعارات، البصمة، تسجيل الخروج.
- + شاشة «قواعد اللعبة» الشفافة (قراءة فقط للكل).

## 3. شاشات المتطوع/المدرب (Volunteer)

### S30 — اليوم (مدرب)
- 🧩 كارت محاضرة اليوم مع عداد تنازلي + [ابدأ الجلسة] · إحصاءات سريعة (نسبة حضور مجموعاتي هذا الشهر · أعذار معلقة بشارة عداد).

### S31 — مجموعاتي (My Batches)
- 🧩 بطاقة لكل باتش: الكورس، الجدول، X طالب، متوسط الحضور، شريط تقدم (محاضرة 3/8)، حالة (نشطة/مكتملة).

### S32 — الجلسة الحية (Live Session) — *شاشة العرض الكبيرة*
- 🎯 تُعرض على الشاشة/البروجكتور — تعمل أيضًا على هاتف المدرب.
- 🧩 **QR دوّار عملاق** (يتجدد كل 25 ثانية + حلقة عداد تدور) · كود 6 أرقام احتياطي · **عدّاد حضور حي** «18 من 25» مع آخر 3 حاضرين بأفاتارات تنزلق · عداد زمني لغلق الحضور · [رصد يدوي] · [إنهاء الجلسة].
- 🗄️ Realtime subscription على الحضور + RPC `start_session` تُرجع جدول التوكنات.
- ✨ كل مسح ناجح: نبضة خضراء في العداد + اسم الطالب يطير للقائمة.
- ⚠️ الحماية: توكن مؤقت + محاولة مسح كود قديم تظهر للطالب «كود منتهي».

### S33 — الرصد اليدوي (Manual Mark)
- 🧩 بحث باسم الطالب + الحالة (حاضر/متأخر) + **سبب إلزامي** («جهازه اتعطل») + توثيق أن المدخل = يدوي في السجل.

### S34 — تقرير الجلسة
- 🧩 3 حقول فقط: إنجزنا ✍️ / التالي 📌 / تحديات ⚠️ + نسبة الحضور تُملأ تلقائيًا.

### S35 — صندوق الأعذار الواردة
- 🧩 بطاقة عذر: الطالب، الجلسة، السبب، المرفق (معاينة) → [قبول 🛡️]/[رفض + ملاحظة إلزامية].

### S36 — ملف الطالب (Student Record)
- 🧩 لمحة الطالب في كل باتشات المدرب: الحضور لكل محاضرة، النقاط، الأعذار، **ملاحظات خاصة** (لا يراها الطالب)، [منح نقاط تقدير] بحد شهري من قاعدة السيرفر.

### S37 — سجل الجلسات والتحليلات
- 🧩 كشف كل جلسة قابلة للتصدير PDF · رسوم: اتجاه الحضور أسبوعيًا، مقارنة المجموعات، أكثر الطلاب التزامًا.

## 4. شاشات المشرف (Admin)

### S40 — لوحة التحكم (Dashboard)
- 🧩 KPI Bento: الفروع، الكورسات النشطة، طلاب نشطون، متوسط الحضور، شهادات هذا الشهر · رسم اتجاه · فلاتر بالفرع.
- ✨ الأرقام Odometer + الرسوم ترسم نفسها.

### S41 — معالج البداية (Getting-Started Wizard) — *موثّق بالكامل في F7/الوثيقة 07*

### S42 — الفروع واللجان (Org Manager)
- 🧩 CRUD فروع (اسم, محافظة, عنوان, مشرف) → داخل كل فرع: لجان + نظرة مصغرة (عدد باتشاته النشطة).

### S43 — الكورسات (Course CRUD)
- 🧩 قائمة الكتالوج + [كورس جديد]: اسم، مجال، وصف، عدد محاضرات قياسي، صورة · حالة: مسودة/منشور/مؤرشف.

### S44 — إنشاء/تعديل مجموعة (Batch Form) — *أهم فورم في التطبيق*
- 🧩 اختيار الكورس → المدرب (بحث من متطوعي الفرع) → السعة → الجدول الأسبوعي (أيام + وقت) → تاريخ بدء → القاعة/الفرع → **معاينة مولّدة تلقائيًا للمحاضرات الثمانية** قبل الحفظ → [نشر].
- ⚙️ تحذير تعارض: نفس المدرب في نفس الوقت؟ → تنبيه قبل الحفظ.

### S45 — قائمة المجموعات
- 🧩 فلترة بالحالة/الفرع · بطاقة: إشغال المقاعد، الحضور، المدرب، حالة.

### S46 — إصدار الشهادات
- 🧩 اختيار باتش منتهٍ → جدول المستحقين ✓ (حضور ≥ القاعدة) وغير المستحقين بالسبب → [إصدار الكل] مع تأكيد.

### S47 — إدارة المستخدمين
- 🧩 بحث + فلاتر دور/فرع → بطاقة → S48 التفاصيل: تغيير الدور، تفعيل/إيقاف، الشارات والنقاط، سجل المحاضرات.

### S49 — قواعد اللعبة (Points & Rules Studio) — *الجوهرة الإدارية*
- 🎯 كل أرقام اللعبة من الشاشة دي مش من الكود.
- 🧩 حقول مرقّمة بقيم افتراضية: نقاط حضور (+10)، متأخر (+7)، نافذة تأخير (15د)، أهلية الشهادة (75%)، حد منح المدرب الشهري، تجميد تلقائي بالعذر (تشغيل)، عتبات المستويات، عتبات الدوري.
- ⚙️ تعديل → معاينة «تأثير التغيير» (مثال: رفع الأهلية لـ 80% = 5 طلاب إضافيين غير مؤهلين في باتش X) → [حفظ] يسري فورًا من السيرفر.

### S50 — استوديو الشارات (Badge Studio)
- 🧩 تفعيل/تعطيل شارة، ضبط شرطها، رفع أيقونتها، ندرتها. الشارات الافتراضية الـ 12 تأتي جاهزة.

### S51 — مراسلات جماعية (Broadcast)
- 🧩 النطاق (فرع/باتش/الكل) + النوع (تنبيه/تذكير/تهنئة) + معاينة كما ستصل → جدولة أو إرسال فوري.

### S52 — سجل العمليات (Audit Log)
- 🧩 من غيّر قاعدة؟ من منح نقاطًا يدويًا؟ متى ولماذا — شفافية إدارية كاملة.

## 5. نظام الحالات الموحّد لكل شاشة (لمنع المفاجآت)

| الحالة | السلوك الموحد |
|---|---|
| Loading (أول مرة) | Skeleton بنفس هيكل المحتوى + Shimmer — لا Spinners وحيدة |
| Loading (إعادة تحميل) | Pull-to-refresh مخصص بحركة لوجو مسار |
| Empty | Lottie/Illustration + عنوان دافئ + CTA واحد واضح |
| Error | بطاقة خطأ عربية هادئة + كود دعم صغير + [إعادة المحاولة] |
| Offline | بانر علوي ثابت + عرض آخر كاش + تعطيل أفعال الكتابة فقط |
| Permission denied | شرح الفائدة قبل طلب الإذن، ولو رُفض نعرض طريق الإعدادات |

> **قاعدة بناء:** لا تُقبل أي شاشة في الـ PR إلا ولها الحالات الست معروفة ومجرّبة (هذا جزء من تعريف الاكتمال في الوثيقة 08).
