# الخطة المتكاملة لإعادة بناء «مسار RTC» من الصفر 🚀

> **الوثيقة الأم (Master Index)** — مشروع إعادة بناء شامل: فلو جديد، شاشات جديدة، جيميفيكيشن كامل، تصميم وموشن على أعلى مستوى، وكل قرار محسوم من أول مرة.
>
> **اسم المشروع:** مسار (Masar) — منظومة تنظيم مراكز التدريب
> **نوع المنتج:** تنظيم وإدارة تدريب فقط (بدون عرض فيديوهات أو محتوى LMS) — الحضور، النقاط، الشهادات، التقارير
> **الستاك المعتمد:** React Native 0.81 + Expo SDK 54 + TypeScript + Supabase (استمرار للبنية الحالية مع ترقية كاملة للمنتج)
> **تاريخ الإصدار:** 2026-08-22 · **الحالة:** خطة معتمدة للتنفيذ

## 🎯 الملخص التنفيذي (اقرأ هذا أولاً)

هنبني **«مسار 3.0»** — مش تحديث، ده منتج جديد بفلسفة جديدة:

### الفلسفة الجديدة في 5 جمل
1. **التطبيق لعبة التزام قبل ما يكون أداة تنظيم** — كل حضور له نقاط فورية، كل استمرارية لها لهب ستريك، كل أسبوع له دوري (League) جديد.
2. **"اليوم" هو مركز الكون** — الطالب يفتح التطبيق يلاقي إجابة فورية لسؤال واحد: *"*إيه اللي عليّ أعمله دلوقتي؟*"*.
3. **حضور بضغطة واحدة وضد التحايل** — QR دوّار يتجدد كل 25 ثانية يمنع التصوير والحضور بالواسطة.
4. **قواعد اللعبة من السيرفر مش من الكود** — قيم النقاط والاستريك ونسب الأهلية يغيّرها الأدمن من لوحة التحكم بدون تحديث التطبيق.
5. **كل حاجة محسوبة من أول مرة** — Design Tokens → عقود RPC → Golden Path E2E قبل أي تلميع بصري.

### الأرقام المستهدفة (KPIs)
| المؤشر | الهدف | القياس |
|---|---|---|
| نسبة حضور قاعات المجموعات النشطة | **85%+** | حضور فعلي / سعة مقاعد |
| زمن تسجيل الحضور الواحد | **< 3 ثوان** | من فتح الماسح حتى تأكيد النجاح |
| الاحتفاظ الأسبوعي للطلاب (W4) | **60%+** | طلاب رجعوا حضروا بعد 4 أسابيع |
| متوسط الفريم في كل الشاشات | **60/120 FPS** | Perf Monitor على جهاز متوسط |
| زمن الإقلاع الدافئ | **< 1.8 ثانية** | جهاز فئة Galaxy A52 |

```
        │                             │                               │

        │                             │                               │
  استريك أسبوعي + دوري ◄────── حضوره محسوب تلقائي ◄────────── قواعد اللعبة من لوحة التحكم
        │                             │                               │
  75% حضور = أهلية شهادة                                     يصدر الشهادات بضغطة
        │                                                             │
  شهادة PNG/PDF + شارة + نقاط إنهاء ◄────────────────────────── إشعار فوري للطالب
```

### القرارات المحسومة (Non-negotiables)
- ✅ **لا فيديوهات ولا محتوى تعليمي داخل التطبيق** — تنظيم فقط (حضور، جدولة، نقاط، شهادات، روابط خارجية اختيارية في V2).
- ✅ **أرقام اللعبة كلها من `gamification_rules` على السيرفر** — ممنوع أي ثابت للنقاط داخل كود العميل.
- ✅ **كل منح نقاط أو شارات أو شهادات يتم عبر RPC `SECURITY DEFINER`** — العميل غير موثوق (Zero-Trust).
- ✅ **عربي أولاً RTL + English** بتكافؤ 100% من اليوم الأول.
- ✅ **Dark Mode ليس خيارًا ثانويًا** — يصمَّم بالتوازي مع الثيم الفاتح.
- ✅ **وضع الحركة المخفضة (Reduced Motion)** محترم في كل أنيميشن.

## 🧩 الهيكل المعماري المختصر

```
masar-3/
├── src/
│   ├── app/            # نقطة الدخول، مزوّدو السياق، Navigation Container
│   ├── design/         # نظام التصميم: tokens, theme, typography, glass, motion presets
│   ├── features/       # التقسيم بالميزة (Feature-Sliced)
│   │   ├── auth/       # OTP, اختيار الدور
│   │   ├── today/      # شاشة اليوم (مركز القيادة)
│   │   ├── explore/    # كتالوج الكورسات
│   │   ├── journey/    # خريطة رحلة الكورس (Duolingo-path للحضور)
│   │   ├── attendance/ # الماسح، QR الدوّار، كشف الحضور
│   │   ├── gamification/# النقاط، الاستريك، الدوري، الشارات
│   │   ├── certificates/
│   │   ├── sessions/   # إدارة الجلسات للمدرب
│   │   ├── org/        # الفروع واللجان والكورسات والباتشات (للأدمن)
│   │   └── profile/
│   ├── shared/         # مكونات مشتركة، هوكس، أدوات
│   ├── data/           # عميل Supabase، RPC contracts، repositories، كاش
│   └── i18n/           # ar / en + فحص التكافؤ الآلي
└── supabase/           # migrations, rpc functions, seeds (نسخة قابلة للمراجعة)
```

> التفاصيل الكاملة في [وثيقة المعمارية](06-architecture-database.md).
