# Accessibility

Target: WCAG 2.2 AA.

- Contrast 4.5:1 body / 3:1 large
- Dynamic type to 200% without clipping
- Reduced motion: fade, no explosions
- Roles/labels/state on interactive elements
- Scanner has 6-digit fallback if camera denied
- Status messages announced (celebration `accessibilityRole=alert`)

Real-device VoiceOver/TalkBack: **NOT VERIFIED**.
