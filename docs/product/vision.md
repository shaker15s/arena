# Vision — Masär

Masär is an **operating system for the training experience**, not an LMS, CRM, or attendance gadget.

A student should open the app and know what matters today. An instructor should run a session without fighting the UI. An admin should see what needs attention and act.

Complexity lives on the server. The user lives a simple, Arabic-first, accessible, trustworthy product.
