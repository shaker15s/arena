# Personas

## Student
Goal: “What happens to me now?” Check in, keep streak, finish course, earn certificate.
Frequency: daily around session time. Low information density.

## Instructor / volunteer
Goal: “What must I do in this session?” Start, QR, roster, excuses, close.
Frequency: session days. Medium density.

## Admin / supervisor
Goal: “What needs intervention?” Conflicts, pending excuses, certificates ready, empty groups.
Frequency: all day. High density, search-first.
