# User journeys (golden paths)

## Student
Sign-in → complete profile → Explore → join batch → Today shows next/live session → Scan → success (+XP) → Journey → certificate when eligible.

## Instructor
Today (teaching) → start session → QR → roster/manual mark → close → report → excuses inbox.

## Admin
Dashboard (needs attention) → create course → create batch/schedule → students join → issue certificates → public verify.
