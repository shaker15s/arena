# مسار Masär 3.0 🚀

تطبيق إدارة مراكز التدريب — **عربي أولاً، RTL بالكامل** — مبني على React Native + Expo + TypeScript strict، بواجهة خلفية Supabase، ويعمل **فورًا في الوضع التجريبي بدون أي مفاتيح**.

## المميزات الأساسية

- 🎓 **إدارة كاملة للمركز**: فروع، لجان، كورسات، مجموعات (Batches)، جداول وجلسات.
- 📋 **حضور ذكي**: QR دوّار يتغيّر كل 25 ثانية (ضد التحايل)، كود احتياطي 6 أرقام، تسجيل يدوي بمبرر.
- 🎮 **جيميفيكيشن كامل**: نقاط، إكس بي أسبوعية، ستريك أسبوعي مع درع التجميد، دوري بـ 5 فئات (برونزي → أسطوري)، 12 شارة رسمية، كودوس المدرب بكوتا شهرية.
- 🏆 **شهادات قابلة للتحقق**: سيريال فريد + صفحة تحقق عامة بالـ QR.
- 🛠️ **أدوات المنظمة**: معالج إنشاء دفعة جديدة (6 خطوات)، استوديو القواعد مع معاينة التأثير، بث رسائل، سجل عمليات، إصدار شهادات دفعي.

## التشغيل السريع

```bash
npm install
npx expo start --web     # معاينة الويب RTL
# أو
npx expo start           # ثم امسح QR من تطبيق Expo Go
```

> **التطبيق يشتغل كاملًا في الوضع التجريبي**: محاكي محلي في `src/data/` (ذاكرة + localStorage) بنفس عقود RPC المُراجعة — زمن مُسرَّع، تنقّل حر بين الشاشات، بيانات عضوية واقعية. مفيش شاشة واحدة ببيانات ثابتة.

## خلفية Supabase (المخطط المراجَع)

ملفات `supabase/migrations/0001-0003` هي العقد الخلفي المراجَع في الـ PR: المخطط، عقود RPC (أمنية: SECURITY DEFINER + Idempotency + RLS Zero-Trust)، ووظائف `pg_cron` (إقفال جلسات تلقائي كل 30 دقيقة، تصفية الستريك والدوري فجر كل أحد). طريقة التطبيق للنشر الفعلي:

1. أنشئ مشروع على [supabase.com](https://supabase.com) وفعّل امتداد `pg_cron`.
2. طبّق المايجريشنز بالترتيب:

```bash
supabase db push       # أو الصق الملفات بالترتيب في SQL Editor
supabase db seed       # بذر قواعد اللعبة الـ11 + الـ12 شارة
```

3. وجّه محاكي `src/data/store.tsx` لعميل `@supabase/supabase-js` — الدوال في `src/data/engine.ts` مناظرة اسمًا وسلوكًا لكل RPC: `student_check_in_v2`, `start_session_v2`, `close_session_v2`, `award_kudos`, `admin_update_rule`, `issue_certificates_v2`... التبديل استبدال تنفيذ المحاكي بنداء `supabase.rpc(name, params)` دون لمس الشاشات.

```
src/
├── app/             # App + RootNavigator: KeepAwake، أدوار، تبويبات RTL، ستاكات

│   ├── engine.ts    #   كل العمليات (startSession/checkIn/closeSession/awardKudos/issueCertificates...)
│   ├── store.tsx    #   StoreProvider + hooks (useSession/useToday/useGamification...)
│   ├── rules.ts     #   القاعدة المركزية: نقاط، إكس بي، مستويات، كتالوج الشارات، ثوابت اللعبة
│   ├── seed.ts      #   بذور المحاكي: فروع، كورسات، مجموعات، أعضاء بحسبان واقعي
│   └── types.ts     #   أنواع النطاق كاملة (User/Batch/Session/Attendance/Grid...)
├── design/          # DS: tokens، ثيم فاتح/داكن، مكوّنات (Card/Seg/Sheet/Chip/Metric)،
│                    #   احتفالات (CelebrationModal/CertReveal)، حركات موحّدة
├── i18n/            # قاموسا ar/en (549 مفتاح متطابقة) + useT مع اتجاه RTL/LTR تلقائي

└── features/        # الشاشات، مُنتظمة لكل دور:

    ├── today/       #   شاشة اليوم: إكس بي، ستريك، جلسة اليوم، تنبيهات
    ├── volunteer/   #   كونسول الجلسة الحية + البشري، تسجيل الحضور، الكودوس، فريق الآن
    ├── gamification/#   الستريك، الدوري الأسبوعي، الإنجازات، الإكس بي، فريقي
    ├── certificates/#   شهاداتي + معاينة + صفحة تحقق بسيريال
    ├── explore/     #   كتالوج الكورسات + طلب الانضمام
    ├── excuses/ + journey/ + notifications/ + profile/ + verify/
    └── org/         #   لوحة القيادة، معالج الدفعة (6 خطوات)، إدارة الفروع،
                     #   استوديو قواعد اللعبة، بث الرسايل، سجل العمليات، إصدار الشهادات
supabase/            # migrations مرقّمة (0001-0003) + seed — تُراجع في الـ PR
```
