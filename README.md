# مسار Masär 3.1 🚀

تطبيق إدارة مراكز التدريب — **عربي أولاً، RTL بالكامل** — مبني على React Native + Expo + TypeScript strict، بواجهة خلفية **Supabase حقيقية**: الدخول بحساب Google، وكل البيانات تُقرأ وتُكتب فعليًا في Postgres. **لا يوجد أي وضع تجريبي أو بيانات وهمية.**

## المميزات الأساسية

- 🔐 **الدخول بحساب Google فقط**: يسحب الاسم والإيميل والصورة، ثم شاشة «أكمل بياناتك» لرقم الموبايل وتعديل الاسم/الصورة واختيار الفرع.
- 🎓 **إدارة كاملة للمركز**: فروع، لجان، كورسات، مجموعات (Batches)، جداول وجلسات.
- 📋 **حضور ذكي**: QR دوّار يتغيّر كل 25 ثانية (ضد التحايل)، كود احتياطي 6 أرقام، تسجيل يدوي بمبرر.
- 🎮 **جيميفيكيشن كامل**: نقاط، إكس بي أسبوعية، ستريك أسبوعي مع درع التجميد، دوري بـ 5 فئات، 12 شارة، كودوس المدرب بكوتا شهرية.
- 🏆 **شهادات قابلة للتحقق**: سيريال فريد + صفحة تحقق عامة بالـ QR.
- 🛠️ **أدوات المنظمة**: معالج إنشاء دفعة (6 خطوات)، استوديو القواعد، بث رسائل، سجل عمليات، إصدار شهادات دفعي.
- 🧊 **Apple Liquid Glass** كثيم أساسي: ضبابية حقيقية، خلفيات متدرجة، ويتبع ثيم النظام (فاتح/داكن/OLED).
- ⚡ **زمن حقيقي**: Supabase Realtime يحدّث الحضور والجلسات والإشعارات فورًا، مع كاش يعمل عند انقطاع الشبكة.

## التشغيل السريع

```bash
npm install
cp .env.example .env      # ثم املأ مفاتيح Supabase
npm run web               # معاينة الويب RTL
# أو
npx expo start            # ثم امسح QR من تطبيق Expo Go
```

> بدون مفاتيح Supabase يعرض التطبيق شاشة «الإعداد مطلوب» — لأننا لا نعرض بيانات وهمية إطلاقًا.
> خطوات الإعداد الكاملة (Google OAuth + RLS + bucket الصور): **[SUPABASE_SETUP.md](SUPABASE_SETUP.md)**.
> تفاصيل ما تغيّر ومقارنة بالمنافسين: **[docs/REALNESS.md](docs/REALNESS.md)**.

## طبقة البيانات

| الملف | الدور |
|---|---|
| `src/data/supabase.ts` | العميل + Google OAuth + رفع الصور + البروفايل |
| `src/data/remote.ts` | قراءة كل الجداول → نموذج التطبيق، وكتابة الفروق (INSERT/UPDATE/DELETE) فعليًا + Realtime |
| `src/data/store.tsx` | الجلسة، الحالة، المزامنة، الكاش، إكمال البروفايل |
| `src/data/engine.ts` | قواعد العمل (حضور/ستريك/دوري/شهادات) — مغطاة بـ 49 اختبارًا |

## التحقق من الجودة

```bash
npm run typecheck     # TypeScript strict — صفر أخطاء
npm run parity        # تطابق مفاتيح i18n عربي/إنجليزي (524 مفتاحًا)
npm run test:engine   # 49 اختبار سلوكي لقلب اللعبة (حضور/Idempotency/ستريك/كوتا/شهادات/دوري)
```
