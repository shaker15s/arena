# مسار Masär 3.2 🚀

تطبيق إدارة مراكز التدريب — **عربي أولاً، RTL بالكامل** — مبني على React Native + Expo + TypeScript strict، بواجهة خلفية **Supabase حقيقية**: الدخول بحساب Google، وكل البيانات تُقرأ وتُكتب فعليًا في Postgres. **لا يوجد أي وضع تجريبي أو بيانات وهمية.**

## المميزات الأساسية

- 🔐 **الدخول بحساب Google فقط**: يسحب الاسم والإيميل والصورة، ثم شاشة «أكمل بياناتك» لرقم الموبايل وتعديل الاسم/الصورة واختيار الفرع.
- 🦅 **تميمة مسار التفاعلية («صقر مسار - فطن»)**: شخصية متجهة Duolingo-style بـ 5 وضعيات شعورية، وتنفس حركي عائم، وتفاعل لمسي نابضي، وفقاعات كلمات تحفيزية حية.
- 🎓 **إدارة كاملة للمركز**: فروع، لجان، كورسات، مجموعات (Batches)، جداول وجلسات مع تصدير تقارير المنظمة بصيغة CSV مشفرة UTF-8 BOM.
- 📋 **حضور ذكي**: QR دوّار يتغيّر كل 25 ثانية (ضد التحايل)، كود احتياطي 6 أرقام، تسجيل يدوي بمبرر.
- 🎮 **جيميفيكيشن كامل**: نقاط، إكس بي أسبوعية، ستريك أسبوعي مع درع التجميد، دوري بـ 5 فئات، 12 شارة، كودوس المدرب بكوتا شهرية، ومشاركة بطاقات الإنجاز على وسائل التواصل.
- 🏆 **شهادات قابلة للتحقق**: سيريال فريد + صفحة تحقق عامة بالـ QR ومسار إعادة إصدار وإلغاء إداري مدقق.
- 🎆 **حركات وتفاعلات دقيقة (2026)**: انفجار قصاصات الزينة الملونة (Confetti Explosion) وشريط تقدم بوميض ناعم (Shimmer Progress).
- 🧊 **Apple Liquid Glass** كثيم أساسي: ضبابية حقيقية، خلفيات متدرجة، لون التمايز الثانوي Amber (`#F59E0B`)، وأزرار 52pt قياسية.
- ⚡ **جاهزية كاملة ونشر على Vercel**: يعمل بسلاسة عبر الويب والأجهزة مع كاش محلي وتحديث Realtime فوري.

## التشغيل السريع

```bash
npm install
cp .env.example .env      # ثم املأ مفاتيح Supabase
npm run web               # معاينة الويب RTL
# أو
npx expo start            # ثم امسح QR من تطبيق Expo Go
```

> بدون مفاتيح Supabase يعرض التطبيق شاشة «الإعداد مطلوب» — لأننا لا نعرض بيانات وهمية إطلاقًا.

> تفاصيل ما تغيّر ومقارنة بالمنافسين: **[docs/REALNESS.md](docs/REALNESS.md)**.

## طبقة البيانات

| الملف | الدور |
|---|---|
| `src/data/supabase.ts` | العميل + Google OAuth + تخزين جلسة آمن (SecureStore على native) + رفع الصور |
| `src/data/remote.ts` | قراءة الجداول → نموذج التطبيق + Realtime تدريجي. **لا يوجد أي مسار كتابة مباشر من العميل** — كل الكتابة عبر RPCs |
| `src/data/actions.ts` | كل الكتابة الحقيقية: RPCs ذرّية مدققة + طابور الأوامر المؤجلة (run_command) |
| `src/data/store.tsx` | الجلسة، الحالة، المزامنة، كاش مربوط بالمستخدم، طابور الأوفلاين، إكمال البروفايل |
| `src/data/engine.ts` | مرآة حتمية لقواعد العمل (حضور/ستريك/دوري/شهادات) للاختبارات والعرض — ليست حدًا أمنيًا |

## التحقق من الجودة

```bash
npm run typecheck     # TypeScript strict — صفر أخطاء
npm run parity        # تطابق مفاتيح i18n عربي/إنجليزي (861 مفتاحًا بنسبة 100%)
npm run test:engine   # اختبارات سلوكية لقلب اللعبة (حضور/Idempotency/ستريك/كوتا/شهادات/دوري)
npm run test:rls      # اختبارات منع التحايل/السباق على مرآة المحرك (تجاوز السعة، توكن مزيّف، كوتا)
npm run test:perf     # قياس أداء الاستعلامات والبحث على 5000+ سجل
npm run test:pentest  # اختبارات الاختراق وعزل سياسات RLS ومحددات التردد
npm run test:load     # اختبار التحمل (100 مستخدم متزامن × 1000 عملية)
npm run test:e2e      # حزمة اختبارات التكامل الشاملة للمسارات الذهبية (62 فحصًا)
npm run test:all      # تشغيل كافة الفحوصات السابقة دفعة واحدة
```

> ⚠️ `test:rls` يختبر **مرآة المحرك المحلية** لعقود الخادم، لا سياسات Postgres
> الفعلية. الحد الأمني الحقيقي هو الـ RPCs والسياسات في `supabase/migrations/`.

## البنية

```
src/
├── app/             # App (ErrorBoundary) + RootNavigator: أدوار، تبويبات RTL، ستاكات
├── data/            # عقل التطبيق — واجهة واحدة للوضعين demo/Supabase:
│   ├── engine.ts    #   كل العمليات (startSession/checkIn/closeSession/awardKudos/issueCertificates...)
│   ├── store.tsx    #   StoreProvider + hooks (useSession/useToday/useGamification...)
│   ├── rules.ts     #   القاعدة المركزية: نقاط، إكس بي، مستويات، كتالوج الشارات، ثوابت اللعبة
│   ├── remote.ts    #   القراءة الحقيقية في Supabase + Realtime تدريجي (الكتابة عبر RPCs فقط)
│   └── types.ts     #   أنواع النطاق كاملة (User/Batch/Session/Attendance/Grid...)
├── design/          # DS: tokens، ثيم فاتح/داكن، مكوّنات (Card/Seg/Sheet/Chip/Metric)،
│                    #   احتفالات (CelebrationModal/CertReveal)، حركات موحّدة
├── i18n/            # قاموسا ar/en (658 مفتاحًا متطابقة) + useT مع اتجاه RTL/LTR تلقائي
├── shared/          # format helpers (تواريخ عربية/هجرية by locale، أرقام...)
└── features/        # الشاشات، مُنتظمة لكل دور:
    ├── auth/        #   دخول Google OAuth عبر Supabase + إنشاء بروفايل
    ├── today/       #   شاشة اليوم: إكس بي، ستريك، جلسة اليوم، تنبيهات
    ├── volunteer/   #   كونسول الجلسة الحية + البشري، تسجيل الحضور، الكودوس، فريق الآن
    ├── gamification/#   الستريك، الدوري الأسبوعي، الإنجازات، الإكس بي، فريقي
    ├── certificates/#   شهاداتي + معاينة + صفحة تحقق بسيريال
    ├── explore/     #   كتالوج الكورسات + طلب الانضمام
    ├── excuses/ + journey/ + notifications/ + profile/ + verify/
    └── org/         #   لوحة القيادة، معالج الدفعة (6 خطوات)، إدارة الفروع،
                     #   استوديو قواعد اللعبة، بث الرسايل، سجل العمليات، إصدار الشهادات
supabase/            # migrations مرقّمة (0001-0022) + seed + config.toml — تُراجع في الـ PR
```
